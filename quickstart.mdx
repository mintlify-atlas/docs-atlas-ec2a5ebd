---
title: "Get started with awawausb in minutes"
description: "Install the awawausb Firefox extension and native stub, then verify the setup by listing connected USB devices using the built-in debug page."
---

awawausb requires two components: the Firefox browser extension and a native stub binary installed on your computer. This guide gets you from zero to a working WebUSB setup.

<Steps>
  <Step title="Install the Firefox extension">
    Download the `.xpi` file from the [GitHub Releases page](https://github.com/ArcaneNibble/awawausb/releases) and open it in Firefox. Firefox will prompt you to add the extension.
  </Step>
  <Step title="Install the native stub">
    Download and unzip the native stub archive for your platform, then run the installer:

    - **Linux / macOS**: `./install.sh`
    - **Windows**: `install.bat`

    The installer copies the binary to an appropriate location and registers the native manifest so Firefox can find it.
  </Step>
  <Step title="Verify the setup">
    Click the awawausb icon in the Firefox toolbar and select **List devices**. If your USB devices appear, the extension and native stub are communicating correctly.
  </Step>
  <Step title="Use the WebUSB API">
    Open any HTTPS page, then open the browser console and call:

    ```javascript
    navigator.usb.getDevices().then(console.log)
    ```

    This returns an array of USB devices the page has previously been granted access to.
  </Step>
</Steps>

See the [installation guide](/installation) for full details, including platform-specific notes and how to load a testing build from source.
