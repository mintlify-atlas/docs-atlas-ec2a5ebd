---
title: "Build and run awawausb locally"
description: "Set up a local development environment for the awawausb extension, load it as a temporary add-on in Firefox, and build the native stub from source."
---

Developing awawausb locally involves two parts: loading the extension as a temporary add-on in Firefox and compiling the native stub Rust binary.

<Steps>
  <Step title="Load the extension in Firefox">
    Open `about:debugging` in Firefox, click **This Firefox**, then click **Load Temporary Add-on…**. Browse to `manifest.json` inside the `extension/` directory of the repository.

    The extension reloads from source files on each Firefox session. Click **Reload** on the `about:debugging` page to pick up JavaScript changes without restarting Firefox.
  </Step>
  <Step title="Build the native stub">
    The native stub is written in Rust. Build it with:

    ```bash
    cd native-stub
    cargo build
    ```

    The compiled binary is at `target/debug/awawausb-native-stub` (or `.exe` on Windows).
  </Step>
  <Step title="Register the native manifest">
    Create a native manifest JSON file pointing to your compiled binary and place it in the correct location for your OS. See [native manifest setup](/developer/native-manifest) for the exact file paths and format.
  </Step>
</Steps>

See [Building from source](/developer/building-from-source) for cross-compilation targets, platform-specific notes, and the full Dockerfile used for release builds.
