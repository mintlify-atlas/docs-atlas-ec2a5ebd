awawausb is a Firefox browser extension that brings WebUSB support to Firefox. Because Firefox does not natively implement the WebUSB API, this extension bridges the gap by pairing a lightweight browser extension with a Rust-compiled native stub binary that communicates with USB hardware using OS-level APIs.

## How it works

awawausb has two components that must both be installed:

1. **The browser extension** — injects `navigator.usb` and the full WebUSB API surface into every web page. A persistent background script manages device state, user permissions, and message routing between pages.

2. **The native stub** — a small Rust binary that runs alongside the browser and communicates with physical USB devices using OS APIs. Firefox launches it automatically via [native messaging](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Native_messaging) and exchanges JSON over stdin/stdout.

<Note>
Both the extension **and** the native stub must be installed. The extension alone cannot access USB hardware.
</Note>

## Supported platforms

| Platform | Architectures |
|---|---|
| macOS 10.15+ | x86_64, ARM64 (Universal binary) |
| Linux (kernel 4.8+) | x86_64, aarch64 |
| Windows 10+ | AMD64, ARM64 |

## Chrome compatibility

awawausb targets full compatibility with Chrome's WebUSB implementation. The `navigator.usb` object, `USBDevice` class, and all transfer methods behave the same as in Chromium. One known difference: unlike Chrome, the API is only available on the **main page** and not inside [Web Workers](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Using_web_workers).
